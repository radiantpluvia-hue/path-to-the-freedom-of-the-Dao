# 🐉 Xianxia: Toward the Dao

A React-based cultivation game inspired by Xianxia novels, featuring character progression, realm advancement, and spiritual cultivation mechanics.

## 🎮 Game Features

### Character Creation
- **Gender Selection**: Choose between Male and Female
- **Race Selection**: 8 different races including Human, Demon, Spirit, Dragon, Phoenix, Celestial, Asura, and Void
- **Background System**: 5 unique backgrounds that affect starting stats and abilities:
  - Noble Family (wealth and social skills)
  - Common Folk (discipline and body tempering)
  - Street Orphan (cunning and mental fortitude)
  - Scholar Family (insight and dao understanding)
  - Merchant Background (trade skills and resources)

### Cultivation System
- **10 Cultivation Realms**: Progress from Mortal to True Immortal
- **Qi Cultivation**: Gather and refine spiritual energy
- **Breakthrough Mechanics**: Advance through realms with increasing requirements
- **Skill Development**: 6 core skills with experience and leveling systems

### Gameplay Mechanics
- **Meditation**: Primary cultivation method to increase Qi and cultivation power
- **Exploration**: Discover treasures, herbs, and encounter random events
- **Event System**: Dynamic events with meaningful choices and consequences
- **Inventory Management**: Collect and manage spiritual items and resources
- **Save/Load System**: Persistent game progress using localStorage

### Skills System
- **Qi Control**: Mastery over spiritual energy
- **Body Tempering**: Physical cultivation and strength
- **Dao Insight**: Understanding of universal principles
- **Combat Skills**: Fighting techniques and battle prowess
- **Social Skills**: Interaction and reputation management
- **Mental Fortitude**: Resistance to tribulations and mental attacks

## 🚀 Getting Started

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation
1. Clone or download the project
2. Navigate to the project directory
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Game
1. Start the development server:
   ```bash
   npm run dev
   ```
2. Open your browser and navigate to `http://localhost:3000`
3. Begin your cultivation journey!

### Building for Production
```bash
npm run build
```

## 🎯 How to Play

1. **Character Creation**: 
   - Select your gender and race
   - Choose a background that suits your playstyle
   - Enter a name for your cultivator (optional)

2. **Cultivation**:
   - Use the "Meditate" button to cultivate and gather Qi
   - Monitor your realm progress and breakthrough when ready
   - Develop your skills through practice and experience

3. **Exploration**:
   - Venture into the wilderness to find treasures
   - Encounter random events with choices that affect your path
   - Build your inventory with spiritual items

4. **Progression**:
   - Advance through cultivation realms
   - Increase your combat power and spiritual insight
   - Unlock new abilities and opportunities

## 🛠️ Technical Stack

- **Frontend**: React 18 with TypeScript
- **State Management**: Zustand
- **Build Tool**: Vite
- **Styling**: CSS with custom theme variables
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Ma Shan Zheng, ZCOOL XiaoWei)
